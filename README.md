## 📌 Deskripsi Proyek
Proyek ini adalah pembuatan website **CV & Portofolio Statis** untuk memenuhi tugas praktikum pertemuan ke-2 Pemrograman Web. Website ini dirancang menggunakan **HTML5 Semantic** dan **CSS3 (Flexbox & CSS Grid)** murni tanpa mengunakan framework external.

Sesuai dengan *Product Requirements Document (PRD)*, website ini mencakup komponen utama informasi digital mahasiswa secara terstruktur, responsif, dan mudah dibaca.
