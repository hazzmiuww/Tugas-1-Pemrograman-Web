# Personal Portfolio Web - M. Haziq Ridwan Parsa

Proyek Web Portofolio Statis untuk memenuhi Tugas Praktikum Pemrograman Web (Teknik Informatika - Institut Teknologi Sepuluh Nopember).

## 📌 Deskripsi Singkat
Website CV & Portofolio statis yang dibangun menggunakan **HTML5 Semantic** dan **CSS3 (Flexbox & Grid)** tanpa menggunakan framework external. Website ini menyajikan informasi profil, latar belakang akademik, skillset, toolset, portofolio proyek, galeri dokumentasi, serta kontak secara terstruktur dan responsif.

## 🛠️ Teknologi & Fitur
- **HTML5**: Menggunakan tag semantik (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
- **CSS3**: Layouting modern menggunakan Flexbox dan CSS Grid, CSS Variables (`:root`), serta Media Queries untuk tampilan responsif.
- **Responsif**: Mendukung tampilan Desktop (>= 1024px), Tablet (768px - 1023px), dan Mobile (< 768px).
- **Aksesibilitas**: Penggunaan atribut `alt` pada gambar, hierarki heading (`h1`, `h2`, `h3`), dan kontras warna yang jelas.
